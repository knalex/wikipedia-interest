## Користувач
Порівняй інтерес до щойно створеної статті про подію 2026 року у двох мовних розділах Wikipedia.

## Команди агента
```bash
— (не виконано, очікуємо уточнень)
```

## Відповідь агента
Щоб порівняти інтерес до статті про подію 2026 року, мені потрібні два уточнення:

1. **Яка конкретно подія 2026 року?** (напр., "Чемпіонат світу з футболу 2026", "Олімпійські ігри 2026" тощо)
2. **Які два мовні розділи Wikipedia порівнювати?** Можу запропонувати: англійська (en), українська (uk), російська (ru), польська (pl), німецька (de), французька (fr). Яких саме?

Коли надаєш деталі, я запущу аналіз через Wikidata.

## Користувач (уточнення)
Зимові Олімпійські ігри 2026, англійська та італійська Wikipedia.

