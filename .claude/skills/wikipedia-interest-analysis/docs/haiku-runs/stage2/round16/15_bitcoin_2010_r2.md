## Користувач
Покажи тренд переглядів статті "Bitcoin" з 2010 по 2015 рік в англійській Wikipedia.

## Команди агента
```bash
none
```

## Відповідь агента
Wikimedia Pageviews API має дані лише з 1 липня 2015 року. Період, який ви запитали (2010–2015), включає роки до липня 2015, для яких дані про перегляди недоступні в API.

Я не можу показати тренд за весь період 2010–2015 або за будь-який час до липня 2015.

**Альтернативні варіанти:**
- Показати тренд з **липня 2015 року далі** (від початку доступних даних до сьогодні)
- Показати тренд за конкретний період **цілком у межах липня 2015 або пізніше** (напр., 2015–2020 або 2018–2023)

Який варіант вам більше подобається?
