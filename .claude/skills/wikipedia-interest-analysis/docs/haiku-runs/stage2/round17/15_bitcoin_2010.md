## Відповідь агента
На жаль, я не можу показати тренд переглядів за період з 2010 по 2015 рік. Wikimedia Pageviews API має дані лише з 1 липня 2015 року. Для раніших періодів історичних даних про перегляди не існує.

Якщо хочеш, я можу показати тренд переглядів статті "Bitcoin" в англійській Wikipedia:
- **З липня 2015 року по теперішній час** — весь доступний період
- **З липня 2015 по кінець 2015 року** — остання половина 2015 року
- Чи якихось інших проміжків після липня 2015 року

Дай мені знати, який період тебе цікавить!
