```bash
cd <skill>
WIKIPEDIA_RESOLVER_CONTACT=you@example.com python3 scripts/resolve_topic.py \
  --query "uk:Зимові Олімпійські ігри 2026" \
  --query "en:2026 Winter Olympics" \
  --targets en,it \
  --user-message "Зимові Олімпійські ігри 2026, англійська та італійська Wikipedia." \
  --out <tmp>/z/19/basket.json

WIKIPEDIA_RESOLVER_CONTACT=you@example.com python3 scripts/fetch_pageviews.py \
  --basket <tmp>/z/19/basket.json \
  --granularity daily \
  --last 90 \
  --out <tmp>/z/19/views.json
```

## Відповідь агента
Тема: «Зимові Олімпійські ігри 2026» (Q4630399).
Період: 2026-06-29 — 2026-09-26 (90 днів). Джерело: Wikimedia Pageviews API, лише перегляди людей (без ботів), разом із перенаправленнями.

- Англійська Wikipedia (en): 186 406 переглядів за період (стаття «2026 Winter Olympics» і 46 перенаправлень).

Абсолютні числа різних мовних розділів не можна порівнювати як міру інтересу: розділи мають дуже різну аудиторію, коректне порівняння (відносні зміни) буде на етапі 3.
