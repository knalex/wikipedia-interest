## Користувач
Ми думаємо додати курс з астрономії до освітнього застосунку. Чи зростає інтерес до цієї теми в україномовній Wikipedia, і наскільки цьому зростанню можна довіряти?

## Команди агента
```bash
cd <skill> && WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/resolve_topic.py \
  --query "uk:астрономія" \
  --query "en:astronomy" \
  --targets uk \
  --user-message "Ми думаємо додати курс з астрономії до освітнього застосунку. Чи зростає інтерес до цієї теми в україномовній Wikipedia, і наскільки цьому зростанню можна довіряти?" \
  --out <tmp>/x/03_2/basket.json

cd <skill> && WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/fetch_pageviews.py \
  --basket <tmp>/x/03_2/basket.json \
  --out <tmp>/x/03_2/views.json
```

**Важливе обмеження**: Аналіз тренду та висновки про зростання або падіння інтересу (етап 3) ще в розробці. На даний момент я можу лише повідомити про суму переглядів, а не про надійність зростання.

Щоб краще оцінити довіру до цих даних, вам потрібно запитати розробників про етап 3 (аналіз трендів), який подасть статистичну оцінку надійності будь-яких висновків про зростання чи падіння інтересу до астрономії.
