
## Користувач
Порівняй інтерес до щойно створеної статті про подію 2026 року у двох мовних розділах Wikipedia.

[Уточнення] Зимові Олімпійські ігри 2026, англійська та італійська Wikipedia.

## Команди агента
```bash
cd <skill> && WIKIPEDIA_RESOLVER_CONTACT=you@example.com python3 scripts/resolve_topic.py \
  --query "uk:Зимові Олімпійські ігри 2026" \
  --query "en:2026 Winter Olympics" \
  --targets en,it \
  --user-message "Порівняй інтерес до щойно створеної статті про подію 2026 року у двох мовних розділах Wikipedia." \
  --user-message "Зимові Олімпійські ігри 2026, англійська та італійська Wikipedia." \
  --out <tmp>/x/19_2/basket.json

cd <skill> && WIKIPEDIA_RESOLVER_CONTACT=you@example.com python3 scripts/fetch_pageviews.py \
  --basket <tmp>/x/19_2/basket.json \
  --granularity daily \
  --last 90 \
  --out <tmp>/x/19_2/views.json
```
