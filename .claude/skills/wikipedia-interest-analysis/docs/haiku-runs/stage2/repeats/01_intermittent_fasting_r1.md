## Відповідь агента
Знайшов тему в обох розділах, але є проблема:

У **чеській Вікіпедії** є стаття: **«Přerušovaný půst»** ✓

У **польській Вікіпедії** нема окремої статті про інтервальне голодування ✗

Це означає, що порівняння переглядів буде нерівноцінним — вимірюватимемо різні набори статей.

Можемо спробувати три варіанти:

1. **Знайти польський переклад терміна** — якщо знаєш, як називається інтервальне голодування польською (напр., «post przerywany»), я можу переоформити запит;

2. **Додати ширше поняття** — можемо включити «піст» (Q44602), який є у обох Вікіпедіях (pl: Post, cs: Půst), але це вже не та сама тема;

3. **Порівняти лише чеськомовні дані** — показати статистику тільки для чеської Вікіпедії (тоді це не порівняння).
