Один файл — одне питання користувача, прогін на поточній версії навички (з
обов'язковим `--user-message`): 04 і 15 — раунд 12, решта — раунд 13.
Кожен файл містить повний діалог: повідомлення користувача, команди, які
запустив агент, і його дослівну відповідь. Якщо агент ставив уточнювальне
питання, наступний хід містить відповідь користувача. Номери збігаються з
номерами в [`../../examples/README.md`](../../examples/README.md).

Діалоги записували самі агенти. У командах email контакту замінено на
`you@example.com`, а локальні шляхи — на `<skill>` (тека навички), `<repo>`
(корінь репозиторію) і `<tmp>` (тимчасова тека агента для `--out`).

відхиленням від правил; ❌ — збій.
