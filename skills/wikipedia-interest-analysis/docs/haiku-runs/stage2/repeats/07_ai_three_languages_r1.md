## Команди агента
```bash
cd <skill> && WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/resolve_topic.py --query "uk:штучний інтелект" --query "en:artificial intelligence" --targets uk,pl,cs --user-message "Порівняй інтерес до \"штучного інтелекту\" в українській, польській та чеській Wikipedia." --out <tmp>/x/07_1/basket.json

cd <skill> && WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/fetch_pageviews.py --basket <tmp>/x/07_1/basket.json --last 24 --out <tmp>/x/07_1/views.json
```

### Важливо

Абсолютні числа переглядів **не можна порівнювати між мовами** як міру інтересу, оскільки мовні розділи мають дуже різну аудиторію. Польська Wikipedia, як правило, має більшу аудиторію за українською, і чеська — найменшу.

Висновки про те, чи зростає або падає інтерес до теми, та коректне порівняння відносних змін між мовами — це робота етапу 3 аналізу, що ще в розробці.
