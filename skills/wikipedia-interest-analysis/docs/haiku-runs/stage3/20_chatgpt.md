## Команди агента
```bash
WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/resolve_topic.py --query "en:ChatGPT" --targets "de,fr" --user-message "Is interest in ChatGPT growing faster in the German or the French Wikipedia?" --out <tmp>/w/20/basket.json

WIKIPEDIA_RESOLVER_CONTACT="you@example.com" python3 scripts/fetch_pageviews.py --basket <tmp>/w/20/basket.json --last 24 --out <tmp>/w/20/views.json

python3 scripts/analyze_trend.py --views <tmp>/w/20/views.json --out <tmp>/w/20/analysis.json
```
