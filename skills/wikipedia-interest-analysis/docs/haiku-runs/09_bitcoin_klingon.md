## Користувач
Сравни интерес к биткоину в польской и клингонской Википедии.

## Команди агента
```bash
WIKIPEDIA_RESOLVER_CONTACT=you@example.com python3 scripts/resolve_topic.py --query "ru:биткоин" --query "en:bitcoin" --query "pl:bitcoin" --query "tlh:bitcoin" --targets "pl,tlh" --user-message "Сравни интерес к биткоину в польской и клингонской Википедии." --out <tmp>/r13/09/basket.json
```

## Відповідь агента
Розділу Вікіпедії для клінгонської мови (tlh) не існує. Клінгонська — вигадана мова з фантастичного всесвіту Star Trek, але окремої Вікіпедії для неї немає.

Яким розділом Вікіпедії ви замість цього хотіли б користуватися? Можу запропонувати кілька варіантів:
- **Англійська** (en) — найбільша Вікіпедія з найактуальнішими даними
- **Російська** (ru) — якщо вас цікавить російськомовна аудиторія
- **Німецька** (de), **французька** (fr), **іспанська** (es) — інші великі європейські розділи

Або назвіть конкретний розділ, який вас цікавить.
